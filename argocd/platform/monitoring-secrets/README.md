# Monitoring secrets

This folder holds SealedSecrets for the monitoring stack. They are generated by
`make seal-secrets` (see [scripts/seal-secrets.sh](../../../scripts/seal-secrets.sh)):

| File | Secret | Used by |
|---|---|---|
| `grafana-admin.yaml` | `grafana-admin` (`admin-user`, `admin-password`) | Grafana login |
| `alertmanager-slack.yaml` | `alertmanager-slack` (`webhook-url`) | Alertmanager → Slack |

SealedSecrets are encrypted with the cluster's public key, so they are safe to commit.
Only the Sealed Secrets controller running in the cluster can decrypt them.
